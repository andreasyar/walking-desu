# Выпуск Walking Desu / wand6 4.2.0

Дата: 2 ноября 2026 года. Задача: [#20](https://github.com/andreasyar/walking-desu/issues/20).
Исходники выпуска: тег `v4.2.0`; основная ветка — `master`.
Доказательства этапа: [RECOVERY-STAGE-14.md](RECOVERY-STAGE-14.md).

## Комплект и запуск

В GitHub Release публикуются клиентский и серверный ZIP/TAR, standalone JAR
сервера и `SHA256SUMS`. **Клиентский архив не содержит изображений.** Перед
запуском скопируйте свой локальный набор спрайтов в
`wand6-client-4.2.0/assets/` по путям из [CLIENT-ASSETS.md](CLIENT-ASSETS.md)
(тот же порядок, что для 3.2: ресурсы вне Git и вне публичных дистрибутивов).

```sh
sha256sum -c SHA256SUMS
tar -xf wand6-client-4.2.0.tar
tar -xf wand6-server-4.2.0.tar
# положите img/summer.png, peasant/poring/tower/canon и coin_stacks_gold.png
# в wand6-client-4.2.0/assets/ согласно CLIENT-ASSETS.md
wand6-server-4.2.0/bin/wand6-server 45001
wand6-client-4.2.0/bin/wand6-client localhost 45001
```

Windows: ZIP и `.bat` из `bin/`. Java 21+; клиенту нужна GUI Java и графическая
сессия. Порт `0` у сервера выбирает свободный порт и печатает
`WAND6_SERVER_PORT=<port>`. Также:
`java -jar wand6-server-4.2.0-standalone.jar 45001`.

## Совместное обновление

Протокол 4.2 несовместим с 3.2 и с промежуточными `4.2.0-dev` / `4.2.0-rc1`.
Клиент и сервер обновляются только одним комплектом. Не смешивайте библиотеки
из разных каталогов или линий.

## Стабильная 3.2 и откат

Стабильная третья линия сохранена в ветке `codex/game-3.x` и в теге/релизе
`v3.2.0`. Правила запуска 3.2 — [RELEASE-3.2.0.md](RELEASE-3.2.0.md). Для отката
остановите пару 4.2 и запустите сохранённый комплект 3.2 на своём порту.

Архивная исходная переработка: `codex/history/4.x-original` (`b9d8a80`).
Исторические теги `v4.0.0` / `v4.1.0` не обозначают готовый выпуск.

## Сборка из тега

```sh
git checkout --detach v4.2.0
./gradlew clean build -PclientAssetsDir=/absolute/path/to/wand6-assets
```

Публичные архивы собираются без изображений (`verifyClientPackaging`).
Локальные GUI-проверки требуют отдельно предоставленный каталог ресурсов.

## Ограничения

- Восстановленный прототип; длительная нагрузка и публичный хостинг не
  проверялись. Windows/macOS не прогонялись.
- Нет постоянной БД, авторизации и автоматического reconnect.
- Прямой путь к точке может упереться в непроходимую клетку; автообход нет.
- Полный сброс волн в GUI не заявляется по одной естественной волне;
  детерминированный цикл проверен отдельно.

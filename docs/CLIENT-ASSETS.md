# Локальные изображения клиента

Клиентский дистрибутив и его JAR не содержат графику. Подготовьте свой
локальный набор изображений и скопируйте `img/` в `assets/` рядом с `bin/`
и `lib/` распакованного клиента:

```text
walking-desu-client-3.2.0/
  bin/
  lib/
  assets/
    required-assets.txt
    img/
      map.png
      ...
```

Все обязательные пути перечислены в `assets/required-assets.txt` относительно
`assets/`. Изображения не скачиваются автоматически. Запускайте клиент
штатным скриптом `bin/walking-desu-client` (в Windows — `.bat`): он добавляет
каталог `assets/` в classpath независимо от текущего рабочего каталога.

```sh
walking-desu-client-3.2.0/bin/walking-desu-client localhost 45001
```

Перед запуском проверьте наличие всех обязательных файлов. Без полного
набора графики игровой клиент работать не сможет.

Для разработки локальные изображения находятся по умолчанию в
`.devcontainer/assets/client/img/`; другой родительский каталог задаётся
`-PclientAssetsDir=/absolute/path/to/client-assets`. `assemble`/`distZip`/
`distTar` собирают дистрибутив без изображений и не требуют их наличия.
`build` запускает визуальные регрессионные проверки и требует локальный набор.
`publishDev` копирует изображения отдельно в локальный `assets/img/`,
не добавляя их в JAR или публичные архивы.

При прямом запуске Java добавляйте каталог ресурсов в classpath явно:

```sh
java -cp 'lib/*:assets' client.WalkingDesu localhost 45001
```

В Windows разделитель classpath — `;`. Настоящие изображения, локальные
dev-артефакты и снимки GUI остаются на машине пользователя.

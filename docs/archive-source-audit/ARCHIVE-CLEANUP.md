# Обработанный архив закрыт

Выполнено 1 ноября 2026 по поручению пользователя. Повторно обследовать эти
источники не требуется: полезные результаты перенесены в Git и локальные наборы.

Удалены:

- `recovered/2026-10-27/` — 1666 файлов: исходные ZIP/tar, JSON Google Code,
  рабочие архивные копии документов и графики, прежние отчёты и инвентаризации.
- `recovered/orphan-branch-package/` — 27 файлов временного пакета импорта,
  побайтово совпадавшего с коммитом исторической ветки.

Всего удалено 1693 файла, 30198154 байта логического размера (около 28,8 МиБ).
Это не оценка освобождённых физических блоков или Git-кэшей.

## Проверки перед удалением

- Проверены содержимое и SHA-256 всех 27 файлов корневого исторического коммита.
- Четыре документа (Dia после распаковки gzip) и семь исходных JSON совпали
  с сохранёнными в Git. В журнале Git есть 141 SVN-запись: 120 сопоставлений
  и 21 запись без восстановленного патча/дерева.
- Повторно проверены все 688 вхождений исходников/скриптов внутри исходных ZIP:
  побайтово известны обычной истории Git либо сохранены как три Java-заготовки.
- Проверены 2153 непустых вхождения изображений/палитр в ZIP/tar и 1630
  распакованных файлов графики: каждое содержимое входит в сохраняемые 701.
- Все 701 уникальное содержимое независимо найдено и проверено по SHA-256
  как в исторической раскладке, так и в галерее просмотра.
- После удаления проверены 4808 сохраняемых файлов и все 120 ссылок by-commit.
  Ветки, HEAD, индекс и `.gitignore` остались без изменений.

Полная побайтовая копия удалённых архивов не оставлялась. Результаты сборки,
297 class-файлов, временные/локальные IDE-конфигурации и полные SVN-базы
сознательно исключены; нужные исходники и читаемые SVN-метаданные сохранены.
Внешние диски, другие архивы и прочие проекты эта очистка не затрагивает.

После удаления обновлены README коллекций: прежние source/source_paths
в манифестах обозначают происхождение, а не существующие входные файлы.
Новые независимые изображения не удалялись; удалены только их старые дубли.

Исторические материалы доступны без восстановления временного пакета:

```sh
git show codex/history/archive-recovery:README.md
git show codex/history/archive-recovery:google-code/commits-page-1.json
git show codex/history/archive-recovery:history/missing-svn-revisions.tsv
```

После завершения обработки по согласованию с пользователем удалены пять
одноразовых скриптов аудита, импорта, очистки, раскладки и галереи, а также
выполненный план, рабочая копия полного отчёта и диагностический evidence.json.
Итого восемь файлов, 509940 байт. Исторический отчёт и существенные результаты
проверок остаются в orphan-ветке; текущие инструкции и манифесты сохранены.
Повторное извлечение архивов для штатной работы с результатами не требуется.

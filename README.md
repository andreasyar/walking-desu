# Walking Desu: исторические материалы

Независимый архивный импорт от 1 ноября 2026. Эта ветка имеет один корневой
коммит и не наследует master. Технический автор коммита — Walking Desu Archive
Import <archive-import@localhost>; исторические авторы сохранены в исходном
SVN-журнале. Рабочие исходники приложения сюда повторно не переносились.

## Состав

- [Документы](documents/): черновик мира, обсуждение архитектуры сервера,
  схема сущностей и задание художнику. Текстовые оригиналы не редактировались.
  Dia-схема сохранена обычным XML, распакованным из исходного gzip.
- [Wiki](wiki/InstallAndRun.wiki): оригинальная разметка InstallAndRun.
- [Google Code](google-code/): исходные JSON проекта, журнала, wiki, задачи
  с комментариями и списка загрузок. Сами пакеты загрузок не включены.
- [Все SVN-ревизии](history/svn-to-git.tsv): 141 запись, из них 120 сопоставлены
  с Git по времени автора до секунды и сообщению без внешних пробелов.
- [Пропуски Git](history/missing-svn-revisions.tsv): 21 запись. Это только
  метаданные; деревьев и патчей этих ревизий в найденных копиях нет.
- [Рабочие копии SVN](history/working-copies.json), [199 узлов r141](history/svn-nodes-r141.tsv),
  [свойства SVN](history/svn-properties.json) и [привязка снимков к Git](history/snapshot-to-git.tsv):
  читаемые экспорты без SQLite, .svn и копий pristine-исходников.
- [Java-заготовки](local-only-stubs/): два пустых main и Hello-пример,
  773 байта суммарно. Сохранены для полноты, игровой логики в них нет.
- [Аудит исходников](audit/SOURCE-AUDIT.md) и [результаты проверок](audit/source-evidence.json).

## Ограничения

GameDraft удалена в SVN r141. Сохранился журнал её создания и правок, но не
тексты версий. Локальный черновик мира не выдаётся за точную копию GameDraft.
SVN-базы относятся к рабочим копиям, а не к серверному репозиторию с историей.
Сопоставление SVN/Git не заменяет проверки отсутствующих оригинальных патчей.
Даты старых файлов не используются как даты импортного коммита.

Графика и палитры исключены по решению владельца проекта. Превью, архивы,
скомпилированные классы, JAR/EXE, результаты сборок и кэши отсутствуют.
В HTML-задании оставлены 18 исторических локальных ссылок на изображения;
сами изображения отсутствуют, эти иллюстрации намеренно не отображаются.
Локальные спрайты и оригинальные архивы остаются в рабочей копии под правилом
`/recovered` в .gitignore; создание этой ветки их не удаляет и не перемещает.

## Происхождение и проверка

[PROVENANCE.tsv](PROVENANCE.tsv) связывает каждый импортированный файл с
источником: имя архива и путь записи, размер, SHA-256 оригинала и результата,
описание преобразования. Строки source-only содержат контрольные суммы
исходных архивов и спецификации импорта, без включения этих источников.
Исходные ZIP могут быть нужны для повторного извлечения, но не для чтения ветки.
Алгоритм экспорта: walking-desu-archive-import-v1. В SVN таблицах время — UTC.
Свойства старых prop-base не приписываются конкретной ревизии без доказательства.
Обе базы r141 сверены: все 199 экспортируемых узлов совпадают.

Исходный Git HEAD при аудите: b9d8a8043b0d2f19f42770f4f3a7eceb849c8bfa.
Исследованные refs перечислены в audit/source-evidence.json; refs/codex
не считались обычной историей проекта. Внешний вид и работоспособность игры
этой веткой не восстанавливаются.

Проверка файлов из корня ветки:

```sh
sha256sum -c SHA256SUMS
```

Манифест покрывает все файлы ветки, кроме самого SHA256SUMS. Происхождение
README, .gitignore и отчётов — явно обозначенные производные материалы импорта.
PROVENANCE.tsv — производная таблица этих источников и не хеширует саму себя.
